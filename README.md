# Clerkship HQ

Unofficial static clerkship organizer prepared for GitHub Pages.

## Access

The site has a client-side password gate for casual sharing with classmates. Share the password separately; do not put it in the public repository.

Because GitHub Pages is static hosting, this is not true server-side authentication. Someone technical could still inspect or copy the page source. Do not publish patient data, private institutional materials, real secrets, or anything that needs enforceable access control.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `clerkship-hq`.
2. Upload these files to the repository root:
   - `index.html`
   - `.nojekyll`
   - `README.md`
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Save. GitHub will give you a public URL after the Pages build finishes.
